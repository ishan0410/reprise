Reprise records one AI-driven run through a legacy web app, compiles it into a typed capability, and replays it deterministically. Policy decides what may happen, and when replay gets stuck a person takes over the same browser.

02

      

        
The run becomes a capability artifact

        
The builder turns the discovery trace into a reviewable JSON contract. The model picked which element to use.
        The builder, not the model, decides how to find it again. Refs, prompts, reasoning and token counts stay in the
        evidence, and the artifact keeps only provenance pointers to them.

      

    

    

      

        

          
    
            
  • Typed inputs and outputs. member_id in, savings_balance out (marked sensitive), plus found, which only an outcome sets.
    • 
            
  • Ranked locator chains, not selectors. role + accessible name → visible text → CSS path → bounding box, each less robust than the one before. Replay records which candidate matched and reports anything past the first as drift.
    • 
            
  • A value-independent extract. "The 4th cell of the row whose label cell is exactly Savings". The balance itself changes between runs, so the locator never depends on it.
    • 
            
  • Phases and checkpoints. bootstrap (sign in) and main each start with a navigate. Checkpoints come from what was actually observed: URL pattern plus title.
    • 
            
  • Declared conditions. Outcomes, recoverables and failures come from a reviewed per-app file merged in by the builder, so adding a case means editing JSON, not code.
    • 
            
  • Least-privilege policy and review status. Only the origins, paths, action types and secrets the recording used. status moves from draft to approved once a person reviews it.
    •

03

      

        
Deterministic replay, with no LLM

        
Replay interprets the artifact. For each step it renders the {{input}}/{{secret}} templates, asks the PolicyGate, resolves
        the target by polling the candidate chain until exactly one visible element matches, acts, re-checks the allowlist, evaluates
        declared conditions, and waits for the checkpoint based on page state, never on fixed sleeps. The replay engine never builds a prompt or calls a model,
        and importing it loads no provider SDK.

04

      

        
Success, business outcome, or failure

        
"No such member" is a correct answer, not a crash. The result contract has three statuses a caller must handle
        differently, and each one maps to its own CLI exit code. All three runs below used the same artifact and differ only in member_id.

      

    

    

      

      

        When a step finishes, or when a target is missing or a checkpoint fails, conditions are checked in this order:
        recoverables→business outcomes→failures
      

      
Recoverables go first because an interstitial can hide whatever is underneath it. Recovery is bounded: each pattern has max_attempts, a phase restarts at most three times, and a retryable app error gets one restart before it becomes a hard failure.

    

  







  

    

      
05

      

        
PolicyGate: safety that doesn't depend on the prompt

        
Nothing reaches the browser without a policy decision. The prompt asks the model to behave, and the gate enforces it whether or not the model does.
        Discovery treats the model as an untrusted source of proposals. Replay isn't exposed to prompt injection at all, because it has no model.

      

    

    

      

        

          
Every action, in both loops

          
    
            
  1. Action type is checked against the allowlist.
    2. 
            
  2. Destination origin and path are matched against glob rules, and explicit denies win. The mock app's /__admin/** fault-injection fixture is always denied.
    3. 
            
  3. Secrets must be on the allowed list and are never allowed in a URL.
    4. 
            
  4. Risk is classified from control names (Confirm, Approve, Delete, Transfer…), URL patterns, and the step's recorded risk. A proposer can raise risk but never lower it. In confirm mode (the default), risky actions go to a human.
    5. 
            
  5. After the action, the URL is checked again, because a click can navigate too.
    6. 
          

          
An artifact's own policy is intersected with the environment's, so a recording can only narrow what an environment allows.

        

        

          

          

          

          

        

      

      

        
Stated limits (from REPORT.md)

        
    
          
  • The allowlist works on URLs and action types, not meaning: it can't tell a real "Search" button from one a malicious page relabelled.
    • 
          
  • Risk classification is heuristic and errs toward asking for confirmation. PII regexes catch structured identifiers, not free-text names.
    • 
          
  • Prompt injection from page content could steer the model during discovery. That's why the gate, not the prompt, is the boundary.
    • 
        

      

    

  







  

    

      
06

      

        
Human handoff on the same browser session

        
An undeclared "password expires in 3 days" interstitial was injected. Replay couldn't classify it, so it wrote an intervention request,
        paused, and ceded the session. From that moment the surface refuses automation actions (ControlViolation). A person dismissed
        the dialog in the same headed window (same cookies, same page) and handed control back with cua-resume. The run finished successfully.

    08
    
      
    
        
    Designed for heterogeneous surfaces
    
        
    The artifact never mentions Playwright or the DOM. css is just one candidate strategy a web adapter knows how to build.
        Perception starts from the accessibility tree because roles and names survive restyling, and desktop accessibility APIs use the same vocabulary.
        One adapter is built. The others are designs, labelled as such.
    
      
    
    
    
    
    
      
    
        
    Surface contract src/cua/surface/base.py
    
        
    Discovery, replay, the PolicyGate and the escalation protocol only ever talk to this interface.
    
        
    
          observe()screenshot()resolve(target)handle_for_ref(ref)
          navigate(url)click(handle)type_text(handle, text)select_option(handle, label)
          press(key)read(handle)settle()describe(handle)
          start_human_recording()stop_human_recording()set_banner(text)url() · title()
        
    
      
    
      
    
        
    built
    Web: PlaywrightSurface
    Chromium, accessibility tree first plus a screenshot. Handles table-based legacy layouts with within / ancestor_role locators. Every recorded run on this page used it.
    
        
    designed, not built
    Legacy web: frame-aware
    Same class, with an optional frame scope on the target descriptor and more reliance on text / within for framesets.
    
        
    designed, not built
    Desktop: UIA / macOS AX
    observe() over the OS accessibility API (the same role/name vocabulary), with bbox candidates resolved against screen captures. The engine, contract, gate and escalation stay the same.
    
      
    
      
    
        
    
          
    Multi-tenant reuse fields + flags built
    
          
    Tenants on the same vendor product share an artifact. target.base_url is bound per tenant (--base-url), app_version records which vendor version the recording used,
          and overrides[] hold per-tenant, per-step changes applied with --tenant X.
    
          
    A tenant registry, per-tenant vaults and drift dashboards are deliberately not built.
    
        
    
        
    
          
    Other seams
    
          
    LLMProvider for models (Gemini first, Groq on 429/503, a scripted provider for offline runs). EscalationHandler for a remote operator console.
          The artifact is the seam for tenants. Storage is files and execution is synchronous: the abstractions wouldn't change if infrastructure were added.

    Run it yourself
    
        
    Python 3.12+ and Chromium. You only need API keys for a live LLM discovery run. Everything else, including discovery through the scripted provider, runs offline.

    python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
playwright install chromium
cp .env.example .env    # keys only needed for live discovery

cua-target-app          # http://127.0.0.1:4000

    The demo pathexit codes: 0 success · 3 business_outcome · 1 failure
    

    # 1. Discover once (live LLM), compile to an artifact
cua-discover --goal "Look up member 10001 and read their current savings balance" \
             --name lookup_member_balance --input member_id=10001

# 2. Replay with a different input, no LLM
cua-replay --artifact artifacts/lookup_member_balance/v1.0.0.json --input member_id=10003

# 3. Business outcome (exit 3) and hard failure (exit 1)
cua-replay --artifact artifacts/lookup_member_balance/v1.0.0.json --input member_id=99999
cua-replay --artifact artifacts/lookup_member_balance/v1.0.0.json --input member_id=40403

# 4. Human handoff on the same window
python demo/escalation_demo.py --artifact artifacts/lookup_member_balance/v1.0.0.json

# 5. Agent-facing catalog
cua-catalog approve lookup_member_balance --by <you>
cua-catalog invoke  lookup_member_balance --arg member_id=10001

# Offline: discovery with the scripted provider
cua-discover ... --provider scripted --script demo/scripts/lookup_member_balance.json
    
        
    
      
    
      
    
        
    What is mocked
    The target is a local mock "Member Services Console" for a credit union. Its /__admin fault-injection endpoints are a test fixture that the allowlist denies.
    
        
    Operator console
    A headed browser plus cua-resume. Control transfer, locking, action recording and resume are real. There is no remote co-browsing.
    
        
    What's next
    A second surface adapter, a tenant registry and drift dashboard, a remote operator console, and a bounded model-assisted re-locate on TARGET_NOT_FOUND. See REPORT.md → Cuts.
